# 📊 Excel Sales Analysis — 7 Practical Tasks

## 📌 Project Overview

This project focuses on applying Microsoft Excel skills to organize sales data, perform calculations, analyze sales performance, and create a simple sales invoice.

The project consists of **7 practical tasks** designed to improve data handling, reporting, and analytical skills using Excel formulas and built-in features.

## 🎯 Project Objectives

- Organize and format sales data professionally.
- Highlight the highest and lowest sales values.
- Apply conditional formatting based on a target.
- Calculate key sales performance metrics using Excel formulas.
- Analyze sales performance by sales representative.
- Retrieve car prices using lookup functions.
- Calculate order totals and prepare a sales invoice.

## 🛠️ Tools & Skills

- **Microsoft Excel**
- Data Formatting
- Conditional Formatting
- Excel Formulas and Functions
- MAX and MIN
- SUM, COUNTA, and AVERAGE
- PivotTables
- XLOOKUP
- Basic Sales Analysis
- Invoice Design

## 📋 Tasks Completed

### Task 1 — Sales Report Formatting

Formatted the sales report to improve readability and presentation.

- Standardized date formats.
- Formatted prices and sales amounts with thousands separators.
- Improved fonts, alignment, borders, and column widths.
- Applied background colors to the headers and data table.

### Task 2 — Conditional Formatting

Used Conditional Formatting to identify the highest and lowest total sales values.

- Highlighted the highest sales amount in green.
- Highlighted the lowest sales amount in red.
- Applied automatic formatting rules to the sales data.

### Task 3 — Target Analysis

Compared sales results against a target of 1,000.

- Highlighted results above the target in green.
- Highlighted results below the target in red.
- Used `MAX` to identify the highest result.
- Used `MIN` to identify the lowest result.
- Referenced the target cell to make the rules dynamic.

### Task 4 — Sales KPI Calculations

Calculated key sales metrics using Excel formulas.

| Metric | Excel Function |
|---|---|
| Total Sales Amount | `SUM` |
| Total Sold Cars | `SUM` |
| Count of Orders | `COUNTA` |
| Average Order Amount | `AVERAGE` |

These metrics provide a quick overview of overall sales performance.

### Task 5 — Sales Representative Analysis

Prepared a sales analysis report to compare the performance of sales representatives.

- Grouped sales by sales representative.
- Calculated total sales for each representative.
- Identified the best-performing representative based on total sales amount.

**Excel Feature:** PivotTable.

### Task 6 — Car Price Lookup & Calculations

Used lookup functions to retrieve car prices from a reference table and calculate the total amount for each order.

- Retrieved car prices based on car type using `XLOOKUP`.
- Calculated total sales for each order using car price and quantity.

**Formula examples:**

```excel
=XLOOKUP(C4,$J$4:$J$9,$K$4:$K$9)
```

```excel
=D4*E4
```

### Task 7 — Sales Invoice

Created a structured sales invoice using Excel formulas and lookup functions.

- Displayed car type, car price, quantity, and total sales.
- Retrieved the car price using `XLOOKUP`.
- Calculated the total sales amount.
- Used `SUM` to calculate the invoice total.
- Improved the invoice layout with formatting and borders.
